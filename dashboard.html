🚀 Quick Setup — 4 Steps to Full Automation

1
Create Google Sheet
Go to sheets.google.com → New → Add column headers from the table above (Row 1). Name the sheet "BookingsDB".
2
Register on Make.com
Go to make.com → Create free account → New Scenario → Click "+" to add a Webhook trigger module. Copy the Webhook URL.
3
Connect WhatsApp Business
In Make.com, add the "WhatsApp Business" module. Connect your WhatsApp Business number (+91 76430 81977). Use the notification templates from the WA Templates tab.
4
Set up Escalation Monitor
Create Scenario 2 with a "Schedule" trigger set to every 15 minutes. Connect it to Google Sheets → filter PENDING → calculate time → route to appropriate WhatsApp message.
💡 Recommended WhatsApp Provider for Make.com: Use AiSensy or Wati.io — both have Make.com integrations, cost ~₹999/month, and work with Indian WhatsApp numbers.
